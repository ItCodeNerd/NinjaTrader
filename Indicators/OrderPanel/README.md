# Order Panel

`ICNOrderPanel.cs` — custom NinjaTrader order entry panel indicator (WPF-based). Adds a fixed on-chart panel with mark buy/sell buttons and locked/enabled input state feedback.

## Install

Copy `ICNOrderPanel.cs` to `Documents/NinjaTrader 8/bin/Custom/Indicators/`, then compile (F5) in NinjaScript Editor.
