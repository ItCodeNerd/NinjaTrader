# Candle panel indicator

Fixed on-screen panel showing last N 5-minute, 15-minute and 1-hour candles, independent of chart's own timeframe. Lets you monitor higher timeframes without switching charts or adding extra panes. Panel position, size, and number of candles per timeframe configurable. Optionally draws support/resistance lines from recent swing high/low on chart's native timeframe. Renders directly on price panel via SharpDX for low overhead.
