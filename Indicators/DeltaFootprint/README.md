# Delta Footprint indicator

Per-price-level buy/sell delta shown as colored numbers on each bar, footprint style. Reveals where aggressive buying vs selling occurred within a bar instead of just net volume, useful for spotting absorption and imbalance at key levels. Requires Tick Replay and bid/ask data enabled in NinjaTrader for accurate trade-side classification.
